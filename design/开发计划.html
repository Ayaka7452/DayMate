01项目概述

基于 4 张手绘设计稿提炼出的产品定位与目标。

产品定位

一个界面克制、操作直觉的倒数日 App。主打两大能力：

  • 倒数日管理：记录未来的期待日（生日、考试、纪念日）和已过去的天数（戒烟、健身、戒咖啡）。
  • Vault：通过密码 + 生物识别，进入一个完全独立的倒数日列表。

目标用户

  • 对日历提醒"通知疲劳"的用户，希望一目了然看到"距离 X 还剩几天"。
  • 需要为一部分事件留出独立空间（送礼物、惊喜、健康追踪等）的用户。
  • 喜欢简洁、纸质手账式视觉风格的用户。

核心场景

  1. 打开 App → 一眼看到所有"倒数日"，按剩余天数排序。
  2. 右下 + 按钮 → 选"事件"或"文件夹" → 选日期 → 完成。
  3. 右上 ⋮ → 进入 Vault → 输入密码/指纹 → 看到独立的倒数日列表 → 离开时点退出。

非目标（v1.0 不做）

  • 云同步、社交分享（v1.x 之后考虑）。
  • 桌面小组件（v1.1 候选）。
  • iOS / 平板适配（v2.0 候选）。
  • 农历/节气（v1.1 候选）。

02功能模块（基于手绘稿）

下面所有模块均来源于 4 张手绘设计稿：主页、条目设计、右上菜单、菜单功能说明 + 文件夹建立方式。

F1

主页 · 倒数日列表

  • 顶部应用名 "DayMate"（手写风格）+ 右上角三点菜单。
  • 列表项显示 事件名 + 剩余/已过天数，例如"下次生日 还有 3 天"。
  • 每行右侧"汉堡"把手支持长按拖动排序。
  • 右下角悬浮圆形 + 按钮：点击弹出底部弹层（事件 / 文件夹）。
  • 空状态：插画 + 提示"轻点 + 创建你的第一个倒数日"。
F2

事件 / 文件夹 · 新建与编辑

  • 事件：标题、目标日期、是否每年重复、是否置顶、是否仅在 Vault 中可见、备注、颜色标记。
  • 文件夹：名称、图标/emoji、颜色、置顶、是否含 Vault 子项。
  • 编辑页支持删除（二次确认）。
  • 表单字段做最小可用校验：标题非空、日期合法。
F3

文件夹与分类

  • 主页可下钻到文件夹查看子项。
  • 文件夹支持拖入事件（批量管理模式时）。
  • 顶部面包屑 / 返回手势回到上一级。
  • 支持文件夹重命名、置顶、删除（删除时事件可选择移出或一并删除）。
F4

列表项 · 设计与排序

  • 显示文案：【事件名】还有 N 天 / 【事件名】已过 N 天。
  • 已过事件默认折叠到分组"已过去"，可展开。
  • 排序：按"剩余天数升序" / "剩余天数降序" / "手动" / "最近修改"。
  • 长按弹出操作：编辑、置顶、移入文件夹、移入 Vault、删除。
F5

批量管理

  • 从右上菜单进入"管理模式"。
  • 每行左侧出现多选框，可多选。
  • 底部 ActionBar：全选 / 删除 / 移入文件夹 / 移入 Vault / 取消。
  • 拖动把支持拖到文件夹（实现：拖到顶部分组或侧边抽屉中的文件夹）。
  • 右上角显示"完成"按钮退出管理模式。
F6

Vault（App 特色）

  • 入口：右上菜单 → Vault。首次使用需设置密码；密码长度 ≥ 6 位。
  • 登录方式：密码 + 系统生物识别（BiometricPrompt，用户已在系统设置开启指纹/面容时可用）。
  • 进入后看到独立的倒数日列表（与主空间完全隔离的 UI 副本）。
  • 顶部持续显示"🔒 Vault"标识 + 退出按钮（任何时间可一键退出）。
  • 退出后立即清空屏幕截图防护标志位（FLAG_SECURE），并锁定主空间访问（需重新认证）。
  • 支持修改密码、关闭生物识别、忘记密码（安全问题或销毁式重置）。
F7

设置

  • 主题：跟随系统 / 始终浅色 / 始终深色（"自动黑白主题"指此）。
  • 字体：默认手写风格（应用名）可关闭。
  • 每周第一天（周一/周日）。
  • 列表默认排序。
  • Vault 超时自动锁定：立刻 / 1 分钟 / 5 分钟 / 永不（应用切换时计算）。
  • 通知与提醒（v1.x 候选）。
F8

关于

  • App 图标、版本号、构建号。
  • 开源许可、致谢、隐私政策链接（v1.0 发版前提供占位）。
  • 反馈邮箱、GitHub 仓库（如开源）。
  • "检查更新"按钮（如上架应用市场）。

03UI 设计规范

尽量贴合手绘稿的纸质、手账风格；建议通过 Figma 二次细化后再编码。

视觉风格

  • 浅色背景 #FAFAF7，纸张感；深色背景 #1A1A18，墨水感。
  • 主色：墨绿 #2F5D62；强调色：暖橘 #C97A3B。
  • 字体：标题"DayMate"用手写体（推荐 Caveat / Ma Shan Zheng，本机内嵌或下载到 assets/）。
  • 列表项：1.2–1.5 间距，无强分割线，使用留白 + 轻底色分块。
  • 圆角 12dp；阴影轻；不使用 Material 默认过强的强调色。

交互规则

  • + 按钮：底部弹层（BottomSheet）选择"事件 / 文件夹"。
  • 右上 ⋮ 菜单：DropdownMenu（紧凑、4 项）。
  • 拖动排序：长按 0.4s 进入拖动，震动反馈（HapticFeedback）。
  • 进入 Vault：模态全屏页；退出需主动点"退出"按钮。
  • 所有破坏性操作（删除、清空）需二次确认 Dialog。

04技术选型与架构

为单人/小团队快速迭代设计，倾向"Google 官方全家桶 + 最小依赖"。

核心技术栈

维度选型
语言Kotlin 1.9+
UIJetpack Compose (BOM 2024.x) + Material 3
架构MVVM + UseCase 层 + Repository
异步Kotlin Coroutines + Flow / StateFlow
本地存储Room 2.6+（明文区）+ SQLCipher（Vault 区可选）
偏好设置DataStore（Preferences）
依赖注入Hilt
导航Navigation-Compose
列表拖动Reorderable（开源） 或 自研 LazyColumn + detectDragGestures
安全Android Keystore + EncryptedSharedPreferences / EncryptedFile + BiometricPrompt
后台任务WorkManager（提醒，v1.x）
崩溃/统计v1.0 不接；v1.x 接 Firebase Crashlytics（可选）
构建Gradle Kotlin DSL + Version Catalog（libs.versions.toml）
最低 SDKminSdk 26 (Android 8.0) / targetSdk 34

关键三方依赖（建议）

  • androidx.biometric:biometric – 指纹/面容
  • androidx.security:security-crypto – 加密 SharedPreferences
  • androidx.room:room-runtime / room-ktx / room-compiler(KSP)
  • com.google.dagger:hilt-android + hilt-compiler(KSP)
  • androidx.navigation:navigation-compose
  • org.jetbrains.kotlinx:kotlinx-datetime – 日期运算
  • io.coil-kt:coil-compose – 图像（如自定义事件图标）
  • io.github.burnoo.compose.reorderable:reorderable – 拖动排序
  • androidx.compose.material3:material3-window-size-class – 平板适配预留

说明

  • Room 编译器推荐 KSP 而非 KAPT，速度更快。
  • 列表项数量级在数百以内，因此不引入 Paging 库。
  • 不引入 Tailwind/Flutter/RN，统一原生 Kotlin。
关于 Vault 加密策略： v1.0 阶段建议"分区隔离 + Keystore 包裹"。即 Vault 表与主表物理分离，Vault 数据写入 EncryptedFile（密钥放 Keystore），登录态内存中持有解密句柄，退出时立即释放。对普通用户已足够；如未来要做端到端备份再升级到 SQLCipher。

06数据模型设计

两个独立 Room 数据库文件：daymate.db 与 vault.db。

主空间（daymate.db）

Event
- id: Long (PK, auto)
- title: String
- targetDate: LocalDate  // 目标日期
- repeatYearly: Boolean
- note: String?
- color: Int?            // ARGB
- folderId: Long?        // 外键
- sortIndex: Int
- isPinned: Boolean
- createdAt / updatedAt: Long

Folder
- id: Long (PK, auto)
- name: String
- icon: String?          // emoji
- color: Int?
- sortIndex: Int
- isPinned: Boolean
- createdAt / updatedAt: Long

Vault（vault.db，文件级加密）

VaultEvent
- id, title, targetDate,
  repeatYearly, note, color,
  sortIndex, isPinned,
  createdAt, updatedAt
// 不引用 Folder，独立列表

// 额外：VaultMeta（DataStore/SharedPreferences）
- hashOfPassword: String  // PBKDF2 / Argon2
- biometricEnabled: Boolean
- failedAttempts: Int
- lastUnlockAt: Long

关键约定

  • 主空间的 Event 也有 isHiddenInVault: Boolean 字段？v1.0 不做"主空间同步到 Vault"；二者完全独立。
  • 主空间通过 DataStore 存 Vault 是否启用、自动锁时长等开关。

11风险与开放问题

已识别风险

  • Vault 忘记密码：没有云端就无"找回"路径。→ 缓解：进入 Vault 时强烈提示用户牢记密码；提供"销毁重置"作为最后手段。
  • 生物识别降级：低端机或未开启指纹时需回退密码。→ 缓解：BiometricManager.canAuthenticate() 检查 + 总是保留密码路径。
  • 截屏/录屏防护：FLAG_SECURE 在系统截图和"最近任务"缩略图有效，但第三方录屏无法完全防。→ 缓解：明确告知 + 文档说明。
  • 日期与时区：用户跨时区出行时"今天"会偏移。→ v1.0 默认使用设备时区；v1.1 增加"按事件绑定时区"选项。
  • 列表性能：条目过千时排序卡顿。→ 缓解：DAO 上加索引；分页加载（v1.x）。
